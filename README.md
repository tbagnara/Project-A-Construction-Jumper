# Construction Jumper
## Be a daredevil climbing buildings and construction sites in this platforming prototype!  
<img src="https://img.itch.zone/aW1hZ2UvNTA4NzY1MS8zMDQ1NDQ4Ni5wbmc=/original/3%2FcSiG.png" width="100%" alt="Gameplay screenshot of Construction Jumper">  


### What is this?
This is a prototype focused on creating a playable build. The game utilizes free assets from the Unity asset store, levels designed using tilemaps, and minimalistic UI elements.
### Where can I try it?
Available to play at [itch.io](https://troccodog.itch.io/construction-jumper).
